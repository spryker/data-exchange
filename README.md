# DataExchange Module
[![Latest Stable Version](https://poser.pugx.org/spryker/data-exchange/v/stable.svg)](https://packagist.org/packages/spryker/data-exchange)
[![Minimum PHP Version](https://img.shields.io/badge/php-%3E%3D%208.3-8892BF.svg)](https://php.net/)

DataExchange module provides the type-agnostic import and export engine: import jobs, job runs with status and error tracking, the CSV import pipeline executed by the `import:job:run` console command, template and data export, and the Back Office pages to manage them. Concrete data types (for example products) plug in through the DataExchangeExtension interfaces.

## Installation

```
composer require spryker/data-exchange
```
